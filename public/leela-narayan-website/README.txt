LEELA NARAYAN — OFFICIAL PORTFOLIO & ACADEMY WEBSITE
================================================================================

This folder contains the complete, self-contained website for Leela Narayan:

FOLDER CONTENTS:
----------------
1. index.html
   The main website file. Double-click this file or open it in any web browser 
   (Google Chrome, Safari, Microsoft Edge, Firefox, Brave) to run the website.
   No server, terminal, or Node.js installation is required!

2. images/
   Contains all authentic, high-resolution photographs:
   - leela-hero-performance.jpg (Concert recital in traditional pink saree)
   - leela-award-stage.jpg (Stage honors & cultural felicitation)
   - leela-shyamotsava-events.jpg (Shyamotsava cultural event)
   - leela-devotional-ganesha.jpg (Devotional seva in front of deity)
   - leela-students-awards-ganesha.jpg (Student celebrations & award presentation)

FEATURES INCLUDED:
------------------
- Responsive layout for desktop, tablet, and mobile.
- 3-Zone navigation with quick links and admissions modal.
- Split-screen hero with background glow and statistics strip.
- Built-in Tanpura Drone Synthesizer (Shruti D) using browser Web Audio API.
- The Three Pillars of Artistry (Vocalist, Educator, Anchor).
- Comprehensive biography, Guru-Shishya lineage, and areas of expertise.
- Complete courses at Leela Narayan School of Performing Arts (LNSOPA).
- Milestone cards with real event photographs (TTD Tirupati, Srisailam, etc.).
- Interactive Raga Sanctuary with live Arohana & Avarohana swara audio player.
- Photo gallery with full-screen lightbox.
- Verified parent & student testimonials.
- Working registration form with direct email & WhatsApp integration.
